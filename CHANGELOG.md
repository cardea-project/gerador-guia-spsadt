# Changelog

## [1.3.0] - 2026-09-16

### Adicionado

- Opção `semFundo` em `GeradorGuiaSPSADT.gerarPdf(guia, { semFundo: true })` e
  `GeradorGuiaConsulta.gerarPdf(guia, { semFundo: true })`, que remove o preenchimento cinza dos
  campos, tabelas e faixas de seção do PDF gerado. Retrocompatível: sem o parâmetro, o layout
  permanece com o fundo cinza atual.
